# Linktree dos Vingadores

Página estática de links com visual moderno e links oficiais confiáveis.

## Como abrir

1. Abra o arquivo `index.html` diretamente no navegador ou
2. Rode um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Observações

- Sem dependências quebradas
- Links com segurança para nova aba
- Layout responsivo e acessível
- Estrutura pronta para evoluir com mais páginas ou redes
